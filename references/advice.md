# 理财与节流建议启发式（个人财务助理）

Agent 在生成报告后，应基于下列启发式给出**个性化、可执行的**对话式建议。
不要空谈理论，要落到「要不要调预算 / 哪类可省 / 目标节奏是否健康」。

---

## 1. 节流建议（基于支出结构）

- **单一分类占比 > 40%**：提示集中度风险。例：「购物占支出 90%，建议为大额数码消费单独设子预算」。
- **超预算分类**：直接点名并给削减动作。例：「餐饮本月超 120，可把外卖频次从 5 次/周降到 3 次」。
- **低频高额异常**：对比历史均值，单笔 > 月支出 20% 且非「居住/金融」类，标记为「需复核」。
- **订阅/金融类**：列出「金融」分类下的手续费/利息/会员，建议清理不用的自动续费。

## 2. 储蓄与理财建议（基于储蓄率）

| 储蓄率        | 解读与建议 |
|---------------|-----------|
| < 10%         | 警戒：攒钱能力不足。优先做「必要支出 vs 想要支出」切割，先设小额自动攒。 |
| 10%–20%       | 及格：尝试把储蓄率提到 20%（50/30/20 法则的收入 20% 用于储蓄）。 |
| 20%–40%       | 健康：可开始配置稳健理财（货币基金/定投），别让钱躺活期。 |
| > 50%         | 优秀但有优化空间：检查是否过度压缩生活质量，或可考虑中长期投资。 |

- **50/30/20 法则**参考线：必要支出 ≤ 50%、想要支出 ≤ 30%、储蓄 ≥ 20%（均以基准币种计）。
- 若有多账户，提醒「把储蓄账户与消费账户隔离」，减少随手花。

## 3. 目标节奏建议（基于 goals）

- **需每月 > 当前月均可攒**：提示目标偏激进，建议延长目标日或提高月储蓄。
- **需每月 ≈ 0 且已接近目标**：鼓励冲刺，给出「最后 N 个月补齐」的具体数。
- **债务目标**：优先于储蓄建议——先把高息债务（信用卡/消费贷）还清再谈投资。
- **已超时（目标日 < 今天）仍未达**：明确告知滞后，重新协商目标日或金额。

## 4. 多币种提示
- 若某币种支出占比上升，提醒关注汇率波动对预算的影响。
- 外币资产建议单独标注，避免与本地消费混算导致误判。

## 5. 投资与定投建议（基于基金持仓 / 储蓄率 / 目标）

- **先应急后投资**：货币型/现金未达 3–6 个月开支前，优先补足应急垫，再启动定投。
- **定投额与储蓄率挂钩**：当月可投 = report 净结余；若储蓄率 < 10%，先控支出而非硬投。
- **持仓再平衡**：某类占比偏离目标 ±10% 即提示再平衡（引擎 `allocate --assets` 已给差值）。
- **主动/行业过热**：该类占比 > 目标 1.5 倍且无基本面支撑 → 建议暂停新增、分批止盈。
- **债券/货币类过低**：在 high 风险下仍偏低 → 提醒「没有底仓，波动会更难受」。
- **定投纪律**：提示不要在下跌月 `dca pause`；止盈后资金回归货币/债券而非消费。

## 6. 建议表达格式
每条建议用「现象 + 数据 + 动作」三要素：
> 「现象：购物占比 90%。数据：355/393。动作：为数码类设 800 元/月子预算，其余转入储蓄账户。」
