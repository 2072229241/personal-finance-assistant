# 报告模板（个人财务助理）

`finance_engine.py report` 输出如下结构。Agent 应在此 Markdown 报表之上，
叠加**对话式解读与建议**（见 `references/advice.md`），不要只把原始数字甩给用户。

---

## 月度报告示例（report --period month --when 2026-10）

```markdown
# 📊 财务分析报告 · 2026年10月（基准币种 CNY）

- 总收入：12000.00
- 总支出：393.50
- 净结余：11606.50
- 储蓄率：96.7%（收入>0 时 = 净结余/收入）

## 分类支出 Top
- 购物：355.00（占支出 90.2%）  ✓ 预算内（限 2000，余 1645）
- 餐饮：38.50（占支出 9.8%）  ✓ 预算内（限 500，余 462）

## 账户维度
- 支付宝：12000.00
- 招行储蓄卡：-38.50
- 美元信用卡：-355.00

## 币种维度（原币）
- CNY：11961.50
- USD：-50.00

## 预算执行
- 餐饮：实际 38.50 / 预算 500.00 → 正常
- 购物：实际 355.00 / 预算 2000.00 → 正常
```

---

## 各区块含义

| 区块           | 作用 |
|----------------|------|
| 总收入/支出/净结余 | 周期内的现金流入、流出与结余（均按基准币种） |
| 储蓄率         | 净结余 ÷ 收入 × 100%；衡量「攒钱能力」的核心指标 |
| 分类支出 Top   | 找出花钱最多的分类，并标注是否超预算 |
| 账户维度       | 多账户视角：哪张卡/哪个钱包在进钱、哪在出钱 |
| 币种维度       | 多币种视角：各币种原币净流量（不换算，仅列原值） |
| 预算执行       | 实际 vs 预算，超支/正常一目了然 |

## 目标追踪示例（goal 子命令自动附加）

```markdown
## 🎯 目标追踪

#1 旅行基金（储蓄）
  [█████░░░░░░░░░░░░░░░] 26.7%
  进度：8000.00 / 30000.00 CNY | 剩余：22000.00
  目标日：2027-10-01（剩 12 个月） | 需每月 1833.33
```

- 进度条长度 20 格，按百分比填充。
- 储蓄：进度 = 已攒 / 目标；债务：进度 = 已偿债占比。
- 「需每月」= 剩余 ÷ 距目标月的月数，是维持节奏的关键提醒。

## 月度资产配置方案示例（allocate + LLM 选基）

```markdown
# 🧭 月度资产配置方案（风险偏好：medium） · 2026-11

- 本月可投金额：3000.00（取自 10 月净结余）
- 当前可配置总资产：20000.00

## 资产类别配置
| 资产类别 | 目标比例 | 本月定投 | 建议类型 | 候选基金 |
|----------|---------|---------|----------|----------|
| 货币型(应急) | 10% | 300 | 货币型 | 余额宝/某某货币A |
| 纯债/固收+ | 30% | 900 | 债券型 | 某某纯债C |
| 宽基指数 | 40% | 1200 | 指数型 | 沪深300ETF(510300) |
| 主动/行业 | 15% | 450 | 混合型 | 易方达中小盘(110011) |
| 海外/QDII | 5% | 150 | QDII | 标普500ETF联接 |

## 再平衡对照（基于现有持仓）
- 主动/行业：当前 65.2% / 目标 15% → 减仓/持有 8234.78（暂停新增）
- 宽基指数：当前 34.8% / 目标 40% → 补仓 2000
- 货币/债券/QDII：当前 0 → 按需建仓

## 定投执行
- dca execute --month 2026-11（计划 #1 #2，合计 1800）
- 其余 1200 按计划补齐债券/货币类后启动新 dca 计划
```

## 输出形式约定
1. **结构化报表**：上述 Markdown（用于存档、贴入笔记、或渲染为表格）。
2. **对话式反馈**：在报表前后用自然语言点出 3 件事——①本期亮点/异常；②与上期对比；
   ③下一步建议。两者结合，既可读又可行动。
